# FDSW-GitHub

## Introducción

Este repositorio contiene el desarrollo y la gestión del proyecto **FDSW-GitHub**. A continuación, se documentan los primeros pasos y cambios realizados.

---

## Primeros Pasos

Para inicializar el repositorio y configurar la rama principal, sigue estos comandos:

````bash
# Inicializar Git en el proyecto
```git init```

# Renombrar la rama principal a 'main2'
```git branch -M main2```
````
